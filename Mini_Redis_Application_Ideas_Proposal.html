1 High-Performance URL Shortener & Analytics Platform (Bitly Style)
✓ Fully Built & Live
Real-world analogue: Bitly, TinyURL — Sub-millisecond URL redirection with memory-bounded caching

Users input long URLs to generate concise short links (/s/linux-kernel). When requested, the service performs an in-memory lookup in 0.018ms, increments real-time click analytics, and executes an instant HTTP 302 redirect. Links support auto-expiry (TTL) and live QR code generation.

How it Uses Mini-Redis C++ Engine:

  • SET url:<code> <dest> EX <ttl>: Stores destination in RAM with optional auto-expiry.
  • GET url:<code>: Constant-time O(1) resolution during HTTP 302 redirect.
  • INCR clicks:<code>: Real-time atomic analytics counter per short link.
  • LRU Eviction: Drops least-accessed links when memory capacity is reached.

Live Demonstration Highlights for Professor:

  • Instant 302 Redirect: Browser redirects in < 1 ms from C++ RAM.
  • Real-Time Clicks Tracker: Click counter increments live on dashboard.
  • Phone QR Scanner: Evaluator can scan generated QR code on mobile camera.
  • TTL Auto-Purge: 1-minute demo links disappear live as countdown reaches 0.
2 API Rate Limiter & Anti-Spam Security Shield (Cloudflare Style)
Ready to Implement
Real-world analogue: Cloudflare, Stripe API Gateways — Traffic shaping and DDoS prevention

An API gateway middleware that protects web servers from brute-force attacks and request spamming. Each client IP address is restricted to a fixed quota (e.g., max 10 requests per minute). Requests exceeding the quota receive an immediate HTTP 429 Too Many Requests response.

How it Uses Mini-Redis C++ Engine:

  • SET rate:<ip> 1 EX 60: Initializes request counter with 60s sliding window.
  • INCR rate:<ip>: Atomically tracks hit counts per incoming client request.
  • TTL rate:<ip>: Checks remaining window time before counter resets.
  • Multi-threading: Thread-safe mutexes handle high-concurrency attack spikes.

Live Demonstration Highlights for Professor:

  • Live Flooder Test: Rapidly click a button 15 times in 5 seconds.
  • Security Lockout: First 10 requests pass green; 11th triggers a red 429 Blocked card.
  • Auto-Unlock Countdown: Live visual timer counts down until the client is unbanned.
  • Systems Value: Directly demonstrates cybersecurity and traffic engineering.
3 Real-Time Multi-User Chat & Session Store (Discord / Slack Style)
Ready to Implement
Real-world analogue: Discord, WhatsApp Web — Ephemeral messaging and authentication session tokens

A collaborative real-time messaging platform where user login sessions and recent conversation channels are held entirely in memory. If a user remains idle, their session token automatically expires. Message logs remain ephemeral in RAM without slow disk write overhead.

How it Uses Mini-Redis C++ Engine:

  • SET session:<token> <user> EX 300: Ephemeral authentication session token.
  • RPUSH channel:<id> <msg>: Fast in-memory message history buffer.
  • Active TTL Sweep: Background cleaner automatically purges inactive sessions.
  • TCP Sockets: Socket connections handle concurrent chat participant streams.

Live Demonstration Highlights for Professor:

  • Multi-Window Chat: Open two browser tabs side-by-side chatting in real time.
  • Session Invalidation: Expire a session token to show security logout live.
  • Zero Disk Lag: Demonstrates why chatting systems prefer in-memory engines over SQL.
4 Live Gaming Leaderboard & Real-Time Scoreboard (BGMI / Chess.com Style)
★ Built & Live
Real-world analogue: BGMI, Chess.com, HackerRank — Millisecond ranking updates under heavy concurrent load

A live competitive scoreboard that dynamically ranks active players based on scores. Traditional databases lock up when hundreds of players score simultaneously; Mini-Redis updates player rankings in memory and computes the top-10 leaderboard with zero perceptible latency.

How it Uses Mini-Redis C++ Engine:

  • SET lb:score:<id> <score>: Instant in-memory score tracking.
  • LRU Ranking Chain: Visualizes top players ordered dynamically by score.
  • AOF Durability: Prevents tournament data loss if game server restarts.

Live Demonstration Highlights for Professor:

  • Live Rank Shuffling: Increment a player's score and watch their card slide up.
  • Simulated Match: Click "Simulate Match" to inject 100 concurrent score updates.
5 Ephemeral OTP & 2-Factor Authentication Service (Zomato / Uber Style)
★ Built & Live
Real-world analogue: Zomato, Uber, Banking OTPs — Secure single-use verification tokens

Simulates an enterprise OTP service. When a user requests a login code, a 6-digit numeric token is saved in Mini-Redis with a strict 3-minute TTL. Once verified or expired, the key is permanently purged from memory so tokens cannot be intercepted or reused.

How it Uses Mini-Redis C++ Engine:

  • SET otp:code:<phone> <pin> EX 45: Auto-expiring one-time password in RAM.
  • DEL otp:code:<phone>: Single-use invalidation upon successful validation.

Live Demonstration Highlights for Professor:

  • Login Flow: Generate OTP → enter code → verify → verify again to show rejection.
  • Expired Token Test: Wait for timer expiry and demonstrate unauthorized access block.
